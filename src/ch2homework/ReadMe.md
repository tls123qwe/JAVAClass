# **계산기 과제 설명**

## 1. 첫 번째 정수(num1) 입력

### - 정수를 입력 시 정수가 아닌 타입을 입력하면 "정수가 이닙니다."문구 출력 후 재입력 할 수 있게 while문으로 작성
### - 반복 조건문 선정이 어려워 true면 반복하기로 돌리고 break를 사용하여 끝냄

## 2. 사칙연산 입력
### - 사칙연산과 "exit"를 입력은 받을 수 있음.
### - "exit"가 아닐 시 while문으로 반복 시작.
### - 사칙연산을 String으로 입력 받은 후 Char으로 변환 후 cla 변수에 선언(다른 방법이 있는거 같으나 수정하면 계속 오류가 발생하여 보류)
### - 여기서 사칙연산 오기입을 방지하기 위해 if문 사용
### - 입력값이 +, -, *, / 이면 다음 정수 입력으로 넘어가게 설계
### - 사칙연산을 잘못 입력 했을 시 "사칙연산 확인"문구 출력 후 재입력

## 3. 다음 정수(num2) 입력
### - 위의 if문이 참이면 다음 정수(num2) 입력
### - num1과 동일하게 정수만 입력할 수 있게 설계

## 4. 입력 값 계산
### - num1, num2, cla을 다 선언하였으면 *calculate 메소드 사용
### - switch문을 사용하여 사칙연산(cla)마다 실행되는 코드 생성
### - 나누기는 0으로 진행 시 오류가 발생되어 if문을 사용하여 실행 방지
### - 계산된 값은 results 리스트에 추가 후 반환

## 5. 추가 계산 진행
### - 진행 여부 문구 출력 후 "exit" 입력 시 현재 결과값(num1) 출력 후 실행 종료
### - 그 외 입력값을 입력 시 [2. 사칙연산 입력]부터 다시 반복(과제 코드에서는 "go"를 요청하나 큰 의미가 없어서 코드 생략)
